# Security policy

## Supported versions

Security fixes go into the latest release of PDR Sign (currently 1.0.x). Please update
before reporting.

## Reporting a vulnerability

Please **don't** open a public GitHub issue for a security problem. Email
**micro_korn@hotmail.com** with:

- what the problem is and what an attacker could do with it,
- the PDR Sign version (About) and how you installed it (snap, .deb or AppImage),
- steps or a sample file to reproduce it (strip any personal data first).

You'll get a reply within 7 days. Once a fix is released, you're welcome to be credited
in the changelog, if you'd like.

PDR Sign works entirely offline on your computer: it doesn't upload documents or
signatures anywhere.
